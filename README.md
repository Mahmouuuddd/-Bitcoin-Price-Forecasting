# ₿ BTC Vision — Bitcoin Price Forecasting Portal

> Interactive Bitcoin price forecasting web app built with Streamlit & Plotly. Supports Prophet and ARIMA models with configurable forecast horizons, confidence intervals, backtesting metrics (MAE/RMSE), and technical indicators (SMA, EMA, Bollinger Bands, RSI). Includes a full data cleaning pipeline via Jupyter.

## 🚀 Features

- **Multi-page Streamlit app** — Home, Forecast, and Statistics pages
- **Two forecasting models** — Facebook Prophet and ARIMA(5,1,0)
- **Configurable parameters** — forecast horizon (7–180 days), confidence intervals (80/90/95%)
- **Backtesting** — MAE and RMSE in USD on an 80/20 train/test split
- **Interactive Plotly charts** — historical price, forecast line, confidence band, forecast-start marker
- **Technical indicators** — SMA-20, EMA-20, Bollinger Bands, RSI-14
- **Statistics page** — EDA dashboard with return distribution, volatility, and descriptive stats
- **Pre-cleaned data pipeline** — `Preparing.ipynb` outputs `btc_cleaned.csv`, loaded automatically

## 🗃️ Data Preparation (Run Once)

Before launching the app, run the cleaning notebook to generate `btc_cleaned.csv`:

```bash
jupyter notebook Preparing.ipynb
```

**What the notebook does:**

1. Loads `dataset/BTC-Daily.csv`
2. Parses the `date` column and OHLCV columns (`open`, `high`, `low`, `close`, `Volume BTC`, `Volume USD`)
3. Sorts chronologically and forward-fills any calendar gaps
4. Flags price outliers via IQR method (flagged, not removed — real market events)
5. Engineers features: SMA-20, EMA-20, Bollinger Bands, RSI-14, daily returns, log returns, 21-day volatility
6. Renames `date → ds` and `close → y` (Prophet-compatible)
7. Validates the dataset and saves `dataset/btc_cleaned.csv`
8. Saves `dataseteda_overview.png` and `datasetreturn_distrib...png`

## 🤖 Model Explanations & Crypto Volatility

### Prophet
Facebook Prophet is an additive time-series model that decomposes the BTC price signal into **trend**, **weekly seasonality**, and **yearly seasonality**. Its automatic changepoint detection (25 changepoints by default) allows it to adapt to Bitcoin's abrupt trend reversals — such as halving events and exchange shocks. Confidence intervals grow non-linearly into the future, reflecting increasing uncertainty over longer horizons.

**Limitation:** Prophet tends to underestimate tail events (flash crashes, black swans).  
**Best for:** Horizons of 30–180 days where seasonal patterns matter.

### ARIMA(5, 1, 0)
AutoRegressive Integrated Moving Average models short-term BTC price momentum as a stationary process:
- **p=5** — uses the last 5 days of prices as autoregressive predictors
- **d=1** — first-order differencing removes the non-stationary exponential trend
- **q=0** — no moving-average term (kept simple for robustness on volatile data)

Confidence intervals widen as √horizon, honestly reflecting BTC's short-term unpredictability.

**Best for:** Short-term horizons of 7–30 days.
